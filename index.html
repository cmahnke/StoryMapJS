Overview

StoryMapJS tells stories on the web that highlight the locations of a series of events. This repository is a TypeScript rewrite of the original Knight Lab viewer: it renders storymap JSON (and IIIF manifests) on modern web maps, without the authoring tool.

The viewer is published as an ES module and works with plain maps as well as gigapixel images served over the IIIF Image API.

Highlights

  • Vanilla ES2022 TypeScript, maps powered by OpenLayers.
  • IIIF Image API support for really big images, from single artworks to multi-page scans.
  • Validated storymap JSON — the JSON schema catches broken data before your readers do.
  • Accessibility and dateline fixes, right-to-left locales, and route distance display.
