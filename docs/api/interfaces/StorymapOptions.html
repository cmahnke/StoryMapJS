    map_area

    map_area: "full" | "left"

    Landscape map layout: "full" (default) spans the whole width with the slide panel fading in over it (the map view is offset so markers clear the panel); "left" limits the map to the left, visible half with an opaque slide panel — no offset needed, fits and constraints align with the visible area directly. Portrait layouts are unaffected.
