# Known Issues — Knight Lab StoryMapJS upstream audit

Every open issue from [NUKnightLab/StoryMapJS/issues](https://github.com/NUKnightLab/StoryMapJS/issues) (109 at audit time, September 2026) triaged against this viewer rewrite. Legacy/editor/backend issues are excluded from testing (`n/a`).

## Summary

## How the tests work

- Reproduction fixtures: `public/examples/issue-*.json` (validated by `npm run validate`).
- Test specs: `e2e/known-issues/issue-<id>*.spec.ts` (one spec per issue; `e2e/known-issues/enhancements.spec.ts` retains only the `#412` routed-lines `test.fixme`).
- Unit-level robustness checks live in `tests/issue-*.test.ts` (Vitest/jsdom).
- `test.fail()` = the bug still applies; the suite stays green while documenting it. Remove the marker when fixing.
