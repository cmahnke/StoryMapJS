# Known Issues — Knight Lab StoryMapJS upstream audit

Every open issue from [NUKnightLab/StoryMapJS/issues](https://github.com/NUKnightLab/StoryMapJS/issues) (109 at audit time, September 2026) triaged against this viewer rewrite. Legacy/editor/backend issues are excluded from testing (`n/a`).

## Summary

| Verdict           | Count | Meaning                                                                                                         |
| ----------------- | ----- | --------------------------------------------------------------------------------------------------------------- |
| fixed             | 28    | verified fixed by a Playwright test (regression guard)                                                          |
| still applies     | 6     | the bug exists in this viewer too — the test is marked `test.fail()` (expected failure, flips green when fixed) |
| partially applies | 10    | part of the report is fixed, part remains; the passing test documents what works                                |
| not implemented   | 22    | enhancement not yet built; `test.fixme()` documents the target behavior where practical                         |

| cosmetic          | 1     | no functional impact                                                                                            |

## How the tests work

- Reproduction fixtures: `public/examples/issue-*.json` (validated by `npm run validate`).
- Test specs: `e2e/known-issues/issue-<id>*.spec.ts` (+ `e2e/known-issues/enhancements.spec.ts` for feature requests).
- Unit-level robustness checks live in `tests/issue-*.test.ts` (Vitest/jsdom).
- `test.fail()` = the bug still applies; the suite stays green while documenting it. Remove the marker when fixing.
