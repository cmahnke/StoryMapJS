    setMapOption

    • setMapOption(name: string, value: unknown): void

      Change a single map option at runtime and apply its effect immediately.

      Runtime-changeable options: map_type (rebuilds the tile layer), show_lines, line_color, line_color_inactive, line_weight, line_opacity, line_dash, line_join, line_follows_path, show_history_line (restyled instantly), map_center_offset (applied on the next navigation), duration, ease, calculate_zoom, map_background_color. All other options only take effect on the next navigation or require re-creating the StoryMap.

      • value: unknown
